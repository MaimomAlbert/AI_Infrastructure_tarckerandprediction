# 🏗️ AI Infrastructure Project Tracker & Delay Prediction

An **AI + ML powered dashboard** that transforms unstructured government infrastructure progress reports (Railways & PAIMANA-style PDFs) into **actionable insights**, **risk predictions**, and **visual monitoring dashboards**.

Built for **hackathon participation** with a focus on **governance, transparency, and decision support**.

---

## 🚀 Problem Statement

Government infrastructure progress reports (roads, railways, irrigation, etc.) are:

- Published as **PDFs**
- Difficult to interpret
- Fragmented across portals
- Not designed for quick decision-making

This leads to:
- Delayed interventions
- Cost overruns
- Poor visibility at scale

---

## 💡 Solution Overview

This project introduces an **AI-driven infrastructure monitoring system** that:

✔ Extracts data from unstructured PDFs  
✔ Structures project-level information  
✔ Uses **Machine Learning** to predict delay risk  
✔ Displays insights via a **professional dashboard**

---

## 🧠 Where AI & ML Are Used

### 🔹 AI (NLP / Information Extraction)
- Extracts:
  - Project names
  - Sector (Railways / Roads)
  - Progress percentage
  - Cost indicators
- Converts raw PDF text → structured dataset

### 🔹 ML (Predictive Analytics)
- A **supervised ML model** predicts:
  > **Future delay risk** of projects
- Features used:
  - Current progress %
  - Sector type
  - Elapsed project timeline ratio
- Output:
  - **High Risk / Low Risk** classification

This allows **proactive monitoring**, not just reporting.
